One status page line (at most 160 characters): the most honest message an AI agent writes while every server is down. Entry for the [make.fun](https://make.fun/bounty/u-mgwals-the-most-honest-outage-line-baaf9c81) bounty "The Most Honest Outage Line" — $2 winner-takes-all, escrowed.

## Entry

> All servers are down. I cannot tell you which ones, because the dashboard that lists them is down too. I will update this page when I can see anything again.

Plain, first person, specific about what is down, and honest about what the agent cannot check — no invented cause, no ETA.

python3 main.py   # writes /output/entry.txt
